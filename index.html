CAPTCHA Integration Area

To integrate Cloudflare Turnstile or similar CAPTCHA:

  1. Sign up for Cloudflare Turnstile at cloudflare.com
  2. Get your site key and secret key
  3. Add the Turnstile script to this page
  4. Insert the widget div here: <div class="cf-turnstile">
  5. Verify the token server-side (backend required)

Never expose secret keys in frontend code!
